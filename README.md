# Maleta Inteligente

**Equipo:** Oscar David de la Cruz Alvarado, Felik Gabriel Ortiz Gomez y Sergio Eduardo Tapia Portal.

## Problema

Al empacar para viajar, trabajar o estudiar, es fácil olvidar algún objeto o no saber si la maleta cumple con el límite de peso; además, una maleta cargada puede resultar difícil de mover.

Además, mover una maleta con una carga considerable puede resultar incómodo y requerir un mayor esfuerzo físico.



Ante esta situación, se plantea desarrollar una maleta inteligente que incorpore herramientas tecnológicas para facilitar el control del peso y mejorar la movilidad del equipaje.

## Usuario

Viajeros, estudiantes, ingenieros y otras personas que necesitan transportar equipaje, herramientas o materiales.

Usuarios que buscan una alternativa más cómoda y funcional para transportar sus pertenencias.



## Sensa / Responde

* Mide el peso total de la maleta con un sensor de peso.
* Envía la lectura al celular por Bluetooth para consultar el peso y comparar cargas; el prototipo también contempla controlar el movimiento de la maleta con un joystick en el celular.
* Conectividad: se plantea transmitir la información del peso al teléfono celular mediante Bluetooth, permitiendo al usuario consultar los datos y comparar diferentes cargas.
* Control de movimiento: se contempla implementar un joystick desde el celular para controlar el desplazamiento de la maleta mediante un sistema motorizado.

## Fabricación

Caja con compartimentos de corte láser para organizar el interior y una base impresa en 3D que sirve de soporte para montar las ruedas nuevas.

La integración de estos elementos permitirá desarrollar una estructura que combine organización, resistencia y funcionalidad.
