# Maleta Inteligente

**Equipo:** Oscar David de la Cruz Alvarado, Felik Gabriel Ortiz Gomez y Sergio Eduardo Tapia Portal.

## Problema
Al empacar para viajar, trabajar o estudiar, es fácil olvidar algún objeto o no saber si la maleta cumple con el límite de peso; además, una maleta cargada puede resultar difícil de mover.

## Usuario
Viajeros, estudiantes, ingenieros y otras personas que necesitan transportar equipaje, herramientas o materiales.

## Sensa / Responde
- Mide el peso total de la maleta con un sensor de peso.
- Envía la lectura al celular por Bluetooth para consultar el peso y comparar cargas; el prototipo también contempla controlar el movimiento de la maleta con un joystick en el celular.

## Fabricación
Caja con compartimentos de corte láser para organizar el interior y una base impresa en 3D que sirve de soporte para montar las ruedas nuevas.

## Nivel
Pro.

## Declaración de uso de IA
Se usó ChatGPT (Codex) para adaptar las notas del equipo a la plantilla del profesor, corregir la redacción y distinguir la medición de peso del control de movimiento previsto para el prototipo.
